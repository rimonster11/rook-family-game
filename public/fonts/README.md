# Bundled fonts

These unmodified fonts are served locally; the game does not contact a font CDN.

- **Lilita One** by Juan Montoreano: display lettering.
  Source: https://github.com/google/fonts/tree/main/ofl/lilitaone
  File: `LilitaOne-Regular.ttf`. License: `LilitaOne-OFL.txt` (SIL OFL 1.1).
- **Nunito** by The Nunito Project Authors: readable rounded interface text.
  Source: https://github.com/google/fonts/tree/main/ofl/nunito
  Upstream file: `Nunito[wght].ttf`, stored here as `Nunito-Variable.ttf`.
  License: `Nunito-OFL.txt` (SIL OFL 1.1).

The CSS names `Rook Display` and `Rook Text` are application aliases only; the
font files and their internal names have not been modified.
